# Contributing to Gobo

Thanks for looking. Issues and pull requests are welcome.

- **Bugs and ideas:** open an issue. Say what you did, what you expected and what happened; a screenshot helps. Never paste a Comfy API key, yours or anyone's.
- **Pull requests:** keep each one small and about one thing, with a test where it fits (`.venv/bin/python -m pytest tests/`, and `cargo test --workspace` for the Rust). Every pull request is read and approved by the maintainer before anything is merged. Nothing reaches the repo on its own.
- **How an accepted change lands:** this repo is published from the one Gobo is developed in. An accepted change is brought into that one and comes out here with the next release, credited to you.
- **License:** by contributing, you agree your work is licensed as the project is: MIT or Apache 2.0 for code, CC BY 4.0 for media and workflows.

Security problems don't go in issues: see [SECURITY.md](SECURITY.md).
